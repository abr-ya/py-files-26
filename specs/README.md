# Legacy Specs

This directory is legacy reference material from the pre-OpenSpec planning workflow.

Current product requirements, roadmap status, active changes, and archived change history live under `openspec/`:

- Current accepted requirements: `openspec/specs/`
- Current roadmap and feature routing: `openspec/backlog.md`
- Active feature work: `openspec/changes/`
- Archived feature work: `openspec/changes/archive/`

Use files in this directory only for historical context and original task traceability. Do not treat `specs/` as the current source of truth.

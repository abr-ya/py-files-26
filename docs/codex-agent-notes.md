# Codex Agent Notes

## Test Validation Handoff

For this project, when validation requires tests, Codex should provide the exact command for the user to run locally.

The user will run the command and paste the result back. Treat the pasted output as validation evidence and summarize it in status or closeout responses.

Avoid spending time running long or environment-sensitive test suites directly unless the user explicitly asks Codex to run them.
